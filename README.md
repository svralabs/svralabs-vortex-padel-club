# Vortex Padel Club — Arena & Social Sanctuary

Luxury athletic modern landing page for Vortex Padel Club. Built with Astro, TypeScript, Native CSS Design Tokens, and GSAP ScrollTrigger animations.

## Features
- Interactive Court Booking Modal with date picker, duration, gear add-ons, and instant price calculator with WhatsApp checkout.
- Facilities dynamic switcher & carousel with smooth GSAP animations.
- Member testimonial carousel with interactive controls.
- Asymmetrical editorial layout with responsive design.
- Performance optimized (<0.5s initial load, responsive typography via CSS `clamp()`).

## Tech Stack
- Framework: [Astro](https://astro.build/)
- Animation: [GSAP](https://greensock.com/gsap/) + ScrollTrigger
- Language: TypeScript
- Styling: Native CSS Custom Properties

## Getting Started
```bash
npm install
npm run dev
```
